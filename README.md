# Portofolio Rido Pandi Sinaga

Kode website [ridopandisinaga.github.io](https://ridopandisinaga.github.io/), termasuk halaman proyek dan catatan teknis.

Untuk menambahkan video atau proyek, gunakan [editor portofolio](https://ridopandisinaga.github.io/portfolio-editor/). Isi formulir, unduh `portfolio.json`, lalu unggah ke folder `_data` di repository ini. GitHub Actions akan memeriksa dan menerbitkan perubahan setelah commit ke `main`.

[Panduan langkah demi langkah](PANDUAN-PORTOFOLIO.md) · [Lihat portofolio](https://ridopandisinaga.github.io/portfolio/) · [Status publikasi](https://github.com/ridopandiSinaga/ridopandiSinaga.github.io/actions/workflows/jekyll.yml)

Website menggunakan Jekyll dan tema [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy), dari [Chirpy Starter](https://github.com/cotes2020/chirpy-starter) karya Cotes Chung. Lisensi MIT tersedia di [LICENSE](LICENSE).
